# 🤖 AI Chatbot

A conversational AI chatbot built with Python, Groq API, and Streamlit.

## ✨ Features
- Real-time AI responses powered by LLaMA 3
- Conversation memory — remembers full chat history
- Clean chat UI with message bubbles
- Deployed live on Streamlit Cloud

## 🛠️ Built With
- Python
- Groq API (LLaMA 3.3)
- Streamlit
- python-dotenv

## 🚀 Live Demo
[Click here to try it live](https://chatbot-6zrqzlskgfgkle33hyx9or.streamlit.app)

## 📦 Run Locally
```bash
git clone https://github.com/sanmitha2905/chatbot.git
cd chatbot
pip install -r requirements.txt
streamlit run app.py
```
